1Problem statement

A small record shop sells three kinds of items: vinyl records, numbered limited-edition vinyls and cassettes. Every item has a name, a price and a stock count. The shop needs to add items, search for them, restock them, sell them, play a preview and give discounts.

Wrong data must be stopped. A price can not be negative, stock can not go below zero, and a sale can not ask for more copies than the shop has. When that happens, the program throws an exception with a clear message and the stored values stay the same.

How the program is organised

When it starts, Main shows a menu with eight topics, one for each part of the syllabus. Each topic runs a short demonstration that uses the store's classes and prints labelled results, so any team member can run one topic and explain the code behind it.

6Limitations and future work

  • Data is created in code and is lost when the program ends. Saving to a file would keep it.
  • The menu runs demonstrations. A full shop menu (add item, sell item, show cart) could use the same classes.
  • More product types, such as CDs or gift cards, would only need a new class that extends Product.
